## Learn week-by-week via branches

Each week lives on its own stacked branch — checking one out gives you exactly the material up to that week, with future weeks absent:

```
master ── scripts ── week-00 ── week-01 ── … ── week-16 ── week-17 ── … ── week-26 ── capstone-and-demo-day
```

```powershell
git checkout week-00     # start here — onboarding + base camps
git checkout week-01     # adds week 1; keep going week by week
git checkout master      # back to scaffolding only (later weeks leave the working tree)
```

`master` is the entry point (scaffolding only). Study the week's folder (starting from its `README.md`); each week folder also contains a `handoff.md` for AI-assisted deep-expansion sessions.

**Forks must include all branches, not just master** — the week-by-week progression lives in the branch chain. Use GitHub's "Fork" (copies every branch); avoid "Import repository" or file-copy forks, which keep only the default branch and break the progression.
