# Deep-Dive: Agno Introduction

Parent overview: [`../01-agno-introduction.md`](../01-agno-introduction.md)

Agno (formerly phiData) is the third agent framework in the program. This
subfolder maps its primitives onto everything you built in Weeks 10–11,
covers the Playground/AgentOS UI, the framework-completion table, and the
phiData→Agno migration notes.

API surface verified against context7 id `/agno-agi/docs`.
