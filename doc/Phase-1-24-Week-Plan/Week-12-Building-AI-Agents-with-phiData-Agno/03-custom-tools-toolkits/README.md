# Deep-Dive: Custom Tools & Toolkits

Parent overview: [`../03-custom-tools-toolkits.md`](../03-custom-tools-toolkits.md)

This subfolder ports your tool discipline into Agno's shapes: function
tools from type hints and docstrings, `Toolkit` classes for grouping and
scoping, the advanced data tools (charts, schema, verification), and the
client battery in toolkit edition.
