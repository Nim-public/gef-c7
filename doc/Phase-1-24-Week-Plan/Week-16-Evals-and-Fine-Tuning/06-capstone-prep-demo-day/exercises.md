# Exercises — Capstone Prep & Demo Day

Stretch tasks and the self-review rubric. The deliverable: the frozen
architecture, the committed roadmap, the demo-day kit, and the 1.0
definition with measured bars.

## 1. The architecture freeze (from 01-architecture-freeze)

**Task:** run the 10-row freeze checklist by *execution*; verify the
five side conditions; commit the checked freeze report.

**Worked approach:** the freeze's discipline is execution-verification —
every row verified by running the thing, not reading it. The side
conditions block the freeze; fix first, freeze second.

**Pass criterion:** 10/10 rows verified; side conditions green; the
freeze committed with its date.

## 2. The sprint roadmap (from 02-sprint-roadmap)

**Task:** fill the sprint table (themes, exit artifacts, gates) from
your weak slices and signals; the first gate onboarded into CI.

**Worked approach:** the roadmap is derived from your data — the weak
slices and the red-team escapes set the priorities. Each gate joins CI
via the W14 onboarding procedure.

**Pass criterion:** the roadmap committed; the first gate in CI; the
priorities cited from the slice/signals reports.

## 3. The demo-day kit (from 03-demo-day-assets)

**Task:** build the demo script; run the fallback rehearsal (five
failure drills in demo order); commit the rehearsal transcript.

**Worked approach:** the kit's discipline is rehearsal — every failure
drill *executed* before demo day, the fallbacks visible, the transcript
committed as evidence.

**Pass criterion:** the demo runs end-to-end; five fallbacks rehearsed;
the transcript committed.

## 4. The 1.0 definition (from 04-version-1-definition)

**Task:** write the five bars with thresholds and gates; the scorecard
measured; the gaps named with owners; the tag rehearsal run on a
scratch branch.

**Worked approach:** the bars are the definition of done — each
threshold measured, each gate wired, the gaps named with owners. The
rehearsal proves the process before the real tag.

**Pass criterion:** the scorecard committed; gaps owned; the rehearsal
green.

## 5. Self-review rubric (the capstone-prep rubric)

| Criterion | Evidence | Points |
|---|---|---|
| Freeze: 10 rows execution-verified, conditions green | freeze report | 4 |
| Roadmap: sprints with exit artifacts and gates | roadmap.md | 4 |
| Demo kit: script, overlay, fallback rehearsal | demo artifacts | 4 |
| 1.0 definition: five bars, gates, gaps owned | scorecard | 4 |
| Rehearsal: tag process on a scratch branch | rehearsal log | 2 |

**Pass bar:** 15/18 to close the core 24 weeks. The freeze (4-pointer)
and the 1.0 definition (4-pointer) are the twin deliverables — the
architecture frozen and "done" defined.

## 6. The core-24-weeks retrospective (the program's closing note)

**Task:** write `reports/core-retrospective.md`: the 24 weeks compressed
into the five bars' evidence chain — what was built, what was measured,
what was trusted, and what was frozen. One page, every claim cited.

**Worked approach:** the retrospective is the program's summary — the
five bars (W16 file 04) as the outline, each bar's evidence chain cited
from its weeks. The gate inventory is the closing image: everything
still running.

**Pass criterion:** the page answers "what does this system do, how is
it verified, and what is frozen?" in one read, every claim cited.

## 7. The extension-weeks bridge (into Phase 3)

**Task:** extend the Week-15 handoff with the extension plan: E1–E10
branches, their themes from the W12 schedule, and each sprint's entry
condition — the bridge from the core program into the extensions.

**Worked approach:** the bridge is the roadmap (file 02-02) expanded to
the extension weeks — each extension's theme, its entry condition, and
its expected artifact.

**Pass criterion:** the bridge committed; the acceptance command green;
the first extension's entry condition checked.

## Pitfalls recap

- Freeze by reading instead of executing — the 1:1 check is the freeze's
  whole value.
- Roadmap sprints without exit artifacts — wishes, not sprints.
- Demo-day kit built but not rehearsed — the fallback rehearsal is the
  insurance; skip it and the demo runs on hope.
