## Who is the ideal participant for this program?

This program is best suited for:

- Software Developers/Engineers looking to transition into AI/LLM (Large Language Model) engineering
- Professionals from a Data Science background who want to deepen their expertise in Generative AI
- Senior Engineering Leaders eager to understand and implement AI-driven solutions

Ideal participants should have experience in coding, application development, and a basic understanding of programming concepts. If you're looking to acquire cutting-edge skills in Generative AI and large-scale language models to accelerate your career, this program is designed for you!

## What are the prerequisites for getting selected/joining the program?

The only key prerequisite is **Python programming knowledge**, as we'll be working extensively with AI frameworks, data handling, and model integration.

- If you have basic Python knowledge, start refreshing your skills if you're keen to pursue this program. We will bring you up to speed during the Base Camp phase, which is covered at the start of the program schedule.
- If you have zero knowledge of Python, you'll need to pick it up on your own before the program begins, as we won't be teaching Python from scratch. However, if you have experience with other programming languages, transitioning to Python should be relatively easy.

## What is the goal of this program?

By the end of this program, you will have built a production-ready, multi-agent AI application that integrates retrieval ranking, response evaluation, and explainability.

This course is designed to equip you with the skills needed to build enterprise-grade AI solutions using Python, NLP, LLMs, RAG, and Agentic AI frameworks — preparing you to work on cutting-edge AI applications in real-world scenarios.

## Can I work on my own capstone project idea?

Yes! You're encouraged to bring your own idea. You can discuss it with a mentor, and if it aligns with the scope of the program, you'll get the go-ahead to build it.

> **Note:** If you're working on your own idea, make sure to bring your own dataset too!

If you don't have an idea, don't worry! We'll provide you with a pool of industry-relevant project ideas to choose from.
